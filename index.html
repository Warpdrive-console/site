Three rules.
No exceptions.

Rule 01

The engine agnostic creed

Warpdrive is a level playing field. Web engines like Scratch, TurboWarp and GB Studio and native engines like Unity, GameMaker and Godot are treated as absolute equals. Web games are not sidelined into a corner of the store. They get the same system level optimization, the same integration, and the same shelf space as a compiled binary.

Rule 02

Empowering the next gen

This is a stage for the developers nobody else is building for. A passionate crowd of young indie creators whose games currently live in a browser tab or a pocket project folder. Warpdrive turns them into real console experiences, with a real store page, a real disc, and a real audience.

Rule 03

Buy once, play everywhere

Buy a game once, digital or physical, and your Rotur account binds it to your universal library. Move from the TV to any handheld in the lineup without paying twice. Saves follow you. Nobody gets charged again for owning the same game on a different shape of plastic.

Open source runtime

Web games run through Chromium with WebGPU. Native ARM binaries land later for full performance titles. Either way you pick the engine, from Unity or GameMaker to Scratch, GB Studio and GDevelop, with dozens of tools in between.

Real culture

We grew up on Newgrounds, itch.io and Game Jolt, and on PS3, Xbox 360 and Wii modding. Open firmware, moddable frontend, homebrew launcher out of the box. Warpdrive would not exist without console modding, so it ships ready for it.

One family.
Two form factors.

Every handheld runs the same silicon so a mobile build is a single target. The home console steps up a tier for the television, with faster memory and a stronger GPU, while staying close enough architecturally that porting stays boring. Both play the same library.

Unified specs.
Diverse forms.

Every handheld in the ecosystem ships with the same processor and the same LPDDR4X memory. Optimize your handheld build once and it performs identically on every device in the line. The shells, the screens and the layouts change. The silicon does not.

  • Shared SoC across every handheld we make
  • LPDDR4X memory, same configuration everywhere
  • One build target, no per device profiling
  • Form factor freedom, different sizes, layouts and price points

The powerhouse.
Built for the TV.

The home console targets the big screen, so it moves up a performance tier. It swaps the handheld memory for faster, higher bandwidth LPDDR5 and carries a noticeably stronger GPU to hold higher resolutions and steadier framerates. Complex scenes stop fighting the memory bus.

  • 8GB LPDDR5, more bandwidth for busy scenes
  • Adreno 643 GPU, comfortable at higher resolutions
  • Disc drive, physical games and collector cases
  • Comparable architecture, so cross porting stays simple

ProcessorQualcomm QCS6490

The QCS6490 is an industrial grade 6nm SoC with an octa core Kryo 670 CPU. It is designed for always on edge devices and has more than enough muscle for indie games. Its consumer counterpart is the Snapdragon 778G, so think Linux gaming performance on industrial silicon: stable clocks, low thermals, and long term availability.

GPUAdreno 643

The Adreno 643 supports Vulkan 1.1 and OpenGL ES 3.2. The real play is WebGPU through Chromium, which hands developers a modern GPU API with compute shaders and instanced rendering, plus enough headroom to push 2D hard and run 3D at respectable framerates. Hardware video decode covers media heavy menus and cutscenes. 4K at 60Hz is on the table if you know how to optimize.

Memory8GB LPDDR5

8GB of LPDDR5 shared between system and GPU. No dedicated VRAM, but the bandwidth is enormous next to what indie games actually ask for, and it is the main reason the home console pulls ahead of the LPDDR4X handhelds on busy scenes. Room to run your game, the social overlay and background downloads at once without choking.

Storage0-256GB eMMC / Micro SD

eMMC onboard from 0 to 256GB, plus a Micro SD slot for expansion. Install disc games to storage and play without the disc later. The OS is light enough to leave most of the drive for your library, and SD cards hot swap so you can carry a collection between units.

Graphics APIVulkan / WebGPU / Wayland

WebGPU is the primary path for web based games. Modern, fast, cross engine. Vulkan is there for native ARM titles that want direct GPU access. Wayland composites the dashboard. Three layers, each doing one job, no bloat in between.

MediaPhysical and digital

An 8x DVD drive reads full size 4.7GB discs in custom purple collector cases. Install once and play forever. The disc is proof of ownership, not a requirement, and buying it registers the game to your Rotur library so it also works on your handheld. Both paths are first class.

Operating systemCustom Armbian derivative

A custom Armbian based Linux build, stripped down for Warpdrive, tweakers and modders alike. Open firmware, fully auditable and fully moddable. The dashboard is a web app you can theme and hack, and the homebrew launcher ships out of the box. It is your console.

Process node6nm

6nm fabrication means good power efficiency and low heat. No fan needed in most scenarios. The chip sips power next to older nodes, which keeps the console quiet, cool and compact. Industrial silicon also means long production availability. If you want the honest version: we were told 6nm is good, and we are repeating it with confidence.

Industrial hardware at the developer's mercy. Push it to its limits, or use it to play 30 year old games. Your call.
